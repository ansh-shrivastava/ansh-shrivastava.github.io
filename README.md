# AI/ML Research Portfolio — updated visual version

Dark, image-led, responsive portfolio based on the four supplied visual references. Built with plain HTML/CSS/JavaScript; no dependencies or build step.

## Preview
Open `index.html` in your browser. Keep the `assets/` folder next to it; the hero is an actual `<img>` element so it does not rely on a CSS background loading.

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_USERNAME`
- `YOUR_EEG_REPO`
- `YOUR_TRANSFORMER_REPO`
- `YOUR_DRONE_REPO`
- `YOUR_WEIGHTS_REPO`
- `YOUR_EMAIL@example.com`
Update education, public location, profile links, and project URLs. Only publish personal details you want public. Verify project descriptions and remove anything you cannot substantiate.

## GitHub Pages
1. Create a public repo named `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `README.md`, `.nojekyll`, and the entire `assets` folder.
3. Go to Settings → Pages and choose deployment from the `main` branch and root folder if needed.
4. Visit `https://YOUR_USERNAME.github.io/` once deployment completes.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site


## Add your own profile photo
1. Choose a clear portrait or professional photo.
2. Copy it into the `assets` folder.
3. Rename it exactly `profile.jpg` (or update the image path in `index.html`).
4. Refresh the page. The photo will appear in the About section. If the file is missing, a styled placeholder explains where it belongs.

Tip: a portrait-oriented image works best; the frame crops to fit automatically. You can use JPG, PNG, or WebP by changing `assets/profile.jpg` in `index.html` to the filename you use.
